# ゴミ箱機能 Implementation Plan

> **本フローではコミットしない**（`/feature`）。

**Goal:** 削除を soft delete（30日復元）にし、ゴミ箱 UI・完全削除・自動 purge を入れる。

**Architecture:** `items.deleted_at` で soft delete。通常 API は生存のみ。ゴミ箱専用 API と `/trash`。日次 Cloud Scheduler が全 PJ purge。trash GET で当該 PJ の機会削除。

**Spec:** `docs/superpowers/specs/2026-11-19-trash-bin-design.md`

**Tech Stack:** Go/MySQL、Angular/Vitest、Cloud Scheduler（deploy）

## Global Constraints

- 境界: `now - deleted_at >= 30×24h` で purge（ちょうど 30d 含む）
- soft 済みへの通常読取・書込は 404。trash 操作は soft 済みのみ
- PageKind に `trash` を足さない。FE 追加ポーリングなし
- Close 列の挙動は変更しない（item-detail の Close ダイアログ非回帰）
- soft delete は `deleted_at` 以外を書き換えない（L-015）。header prefs を読込完了前に全 PUT しない（L-669）
- L-002 / L-037 / L-040
- `/feature` のためコミットしない

### Task 2: BE — trash API（list / restore / hard / purge）

**Files:** trash handlers/repo, handler routes, tests

- [x] **Step 1: 失敗するテスト**
