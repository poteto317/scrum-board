# カード133 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans。順に実装する。

**Goal:** web-dev再起動時、依存一致ならnpm ciを省略する。
**Architecture:** Node起動スクリプトで成功マーカーとnpm lsを検証し、必要な時だけnpm ci。npmサーバーを起動し全子プロセスへシグナルを伝える。
**Tech Stack:** Node標準API/node:test、npm、Compose、Angular
**Spec:** docs/superpowers/specs/2026-11-25-card133-web-dev-design.md

## Global Constraints
稼働中の開発サービス・既存ボリュームを検証で変更しない。本番ビルド・通常npm startを維持する。同じボリュームへの並列書込みは対象外。依存追加なし。

## Review Focus
成功マーカーだけ残った不完全な依存はnpm lsで検知する。
ci失敗や停止ではマーカーを記録せずサーバーを起動しない。
package/lock/runtime/インストール済みlockの変更は再インストールする。
Docker停止シグナルはインストール中もサーバー中も子グループへ転送する。
Linuxのnode_modulesとホスト用node_modulesを混ぜない。
