# Kanban MVP Implementation Plan

**Goal:** Docker MySQLへ永続化するAngular・Goのかんばんを作る。
**Architecture:** Angular standalone + Go REST API + database/sql。HTTPとSQLをRepositoryインターフェースで分離。
**Tech Stack:** Angular 21、TypeScript 5.9、Go 1.26、MySQL 8.4、Docker Compose。
**Spec:** docs/superpowers/specs/2026-11-11-kanban-design.md

## Global Constraints
初期列Todo/Doing/Done。カード縦積み・列横並び。ステータスは詳細画面で変更。ドラッグ＆ドロップはサンプルカードのみ。MySQLはDockerで起動。依存をロックし日本語READMEを用意。

## Review Focus
- 空白名、長過ぎる文字、UnicodeをAPIでも検証する。
- 存在しないカード・列は404/400、重複列は409。
- 保存失敗時は詳細の入力を保持し二重送信を防ぐ。
- ボードに多数のカード・列を置いても表示をはみ出させない。
- 再起動で初期カードを重複登録せず、保存内容を維持する。
