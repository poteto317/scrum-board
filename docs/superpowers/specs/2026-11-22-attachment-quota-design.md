# 設計: 添付のプロジェクト合計上限と同時実行制限（#99）

## 決めたこと

| 事項 | 採用 |
|------|------|
| 合計上限 | **プロジェクト単位** 100 MiB（`item_attachments` の `byte_size` 合計。削除済みアイテムは除外） |
| 同時実行 | アップロード・本文取得で共有セマフォ **4**（満杯時 503） |
| 配信 | 既存の `io.Copy` ストリームを維持（本文をメモリに載せない） |
| 超過 | `ErrAttachmentQuota` → 400 |

## 受け入れ条件

- 合計上限超過のアップロードが拒否される
- 同時取得がメモリを際限なく増やさない（同時スロット制限）
