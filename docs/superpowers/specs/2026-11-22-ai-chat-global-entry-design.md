# AI チャット: ボード／詳細から開ける入口 — 設計

- カード: [#56 AIチャット: ボードとアイテム詳細からチャットを開けるようにする](https://scrum-board-jkcejsb6ka-an.a.run.app/items/56?project=1)
- 前提: [#47 MVP](./2026-11-21-ai-chat-mvp-design.md)（詳細内パネル済み・ボード横断は後続） / [#52 不可状態](./2026-11-21-ai-unavailable-states-design.md) / `ItemAiChat`（アイテム単位・サーバ履歴）
- 日付: 2026-11-22

## 背景

- 完了条件: ボード・バックログ・アイテム詳細のどこからでも開閉できる。ライブ更新（5秒）や DnD と干渉しない。
- 現状: 編集可のアイテム詳細に `ItemAiChat` が**常時インライン**。開閉・Esc・フォーカス復帰なし。ボード／バックログ／ヘッダーに入口なし。
- 親要望: 使いたいときにすぐ開ける（入口は Notion 同様**ページ右下**）。

## 決めたこと

| 項目 | 決定 |
| --- | --- |
| 入口位置 | **ページ右下の固定ボタン**（Notion と同位置感）。`position: fixed; right`＋`bottom` |
| 入口を出すルート | **`/`（ボード）・`/backlog`・`/items/:number`（詳細）のみ**。`/settings`・`/sprints`・`/trash`・`/users` 等では出さない |
| 入口の表示条件 | 上記ルートかつ**ログイン済み**かつ、（詳細なら当該アイテム `canEdit`）または（ボード／バックログならメモリ上の一覧に編集可アイテムが1件以上）。未ログイン・編集可0件・閲覧専用詳細では非表示 |
| 詳細の常時パネル | **やめる**。詳細も同じ開閉パネルに統一 |
| UI 形態 | **ドロワー／浮上面パネル**（既存 `<dialog>` モーダルではない）。Esc で閉じ、閉じ後フォーカスを入口へ戻す |
| アイテム文脈 | チャットは引き続き**アイテム単位**。ボード／バックログではパネル内で対象を選ぶ。候補は**そのページが既に持っている board／backlog 配列のみ**（新規 BE・追加 fetch・他ルートからのキャッシュ読みなし）。各候補は `number`＋`projectId`＋`id`（＝`itemId`）＋`title`。編集不可は disabled |
| 初期対象 | 詳細: ルートの `number`／`projectId`／`itemId` を自動セット。ボード／バックログ: **未選択**（自動選択しない） |
| ルート遷移 | **開いたまま移動してよい**（会話＝サーバ履歴はアイテム単位で残る）。遷移先が入口対象外ルートならパネルを閉じ選択クリア。詳細へ入ったら対象をそのアイテムに上書き。ボード／バックログへ戻ったら対象は維持（一覧に無ければクリア）。プロジェクト切替で開閉・選択とも破棄 |
| セッション保持 | 開閉フラグと選択 **`{ number, projectId, itemId }`** はセッションメモリのみ（リロードで閉じる） |
| 世代（L-037） | `number`／`projectId`／`itemId` 変更で generation を進め、古い履歴／credits を捨てる |
| ライブ更新・DnD | パネル open **だけでは** live refresh を止めない。既存ガード維持。入口は右下で DnD と重ならない |
| キー未設定・枯渇 | **#52 維持**: 入口は開ける。パネル内の入力・送信のみ disabled。履歴・クリア可 |
| credits 読込 | 対象確定後に `getAICredits`。読込中 compose disabled。未オープン時は取得しない |
| フォーカス／キー | 開く: パネル先頭へフォーカス（`afterNextRender`／rAF。実行時に `DestroyRef.destroyed` または前面 `<dialog>` があればスキップ＝L-762）。閉じる: 入口へ戻す前にパネル内 `activeElement` を **明示 `blur()`**（L-397: unmount 前。onBlur だけに頼らない後始末）。Esc／Enter は `isComposing` または `keyCode===229` のとき無視（L-474）。開いた直後のキーリピートが閉じる／送信に届かないようガード（L-408） |
| z-index | ヘッダー（5）・メニュー（最大 6）より上、**コピーバナー（20）より下**。目安 `12`。`<dialog>` top layer より下 |
| 本カード範囲 | **FE のみ**。BE／OpenAPI は変更しない |

## 非目標

- ボード全体を文脈にした横断チャット（アイテム無しの会話）
- ヘッダー／ハンバーガーへの AI 入口
- キー未設定・枯渇を理由に入口ボタンを disabled にすること（パネル内で阻止＝#52）
- 「最近見た」リスト
- `/settings` 等の対象外ルートへの入口
- エージェントのツール実行・自動ステータス変更
- ストリーミング必須化
- Notion UI の完全クローン（位置とすぐ開けることのみ）
- refined（AI 整形）パネルの同型入口

## 利用者体験

1. 条件を満たす画面で右下に「AIに聞く」が出る。
2. 押すとパネルが開く。詳細なら当該アイテムの履歴。ボード／バックログなら対象を一覧から選ぶまで送信不可。
3. Esc または閉じるでパネルが閉じ、フォーカスが入口に戻る。
4. キー未設定・枯渇でもパネルは開けるが、入力・送信は #52 どおり無効。履歴は見られる。
5. ボードの自動再取得やカード DnD は、パネル open だけでは止めない。

## フロント変更概要

- ボード／バックログ／詳細のレイアウト（または `showChrome` かつ対象ルート限定のホスト）に右下入口＋パネルを置く。設定等ではマウントしない。
- パネル内に `ItemAiChat`（必須: `number`／`projectId`／`itemId`）。詳細の常時埋め込みを除去。
- ピッカーは当該ページの既存カード配列のみ。
- テスト: 開閉・Esc（IME 中は閉じない）・フォーカス戻り（destroyed／dialog 時スキップ）、詳細自動対象、ボード未選択時送信不可、blocked でも入口可・compose 不可、詳細から常時パネル消失、対象外ルートで入口非表示。

## 受け入れ条件（#56）

1. ボード・バックログ・編集可のアイテム詳細で右下から開閉できる。設定等の対象外ルートでは入口が無い（テスト）
2. Esc で閉じ、フォーカスが入口に戻る。IME 変換中の Esc／Enter では閉じない・送信しない（テスト）
3. 詳細ではルートのアイテムが対象。ボード／バックログでは対象未選択時に送信できない（テスト）
4. キー未設定・枯渇でも入口は開けるが、パネル内で送信できず POST が走らない（#52・テスト）
5. 詳細ページに常時インラインの AI ブロックが残っていない
6. live refresh／DnD の既存ガードを壊さない（パネル open 単独で poll を止めない）
7. BE／OpenAPI を変更しない
