# 右上の列追加ボタンの削除

見出し右上の列追加ボタンを削除する。かんばん見出し右側の「列を追加」ボタンのみを削除し、ボード右端の列追加タイルと既存ダイアログ・列追加APIは維持する。入口を右端へ統一する小さな表示変更とする。非表示CSSで残すよりテンプレートから削除する方が、不要なフォーカス対象と操作入口を除去できるため採用する。

board.htmlのpage-heading内buttonを削除し、これ専用のmobile用.page-heading .primaryルールを除去する。ヘッダーの文言、レイアウトの大枠、カード操作、列追加機能自体には変更しない。

検証は既存Angularテストと本番ビルド、ブラウザーでヘッダーボタンの消失・残る右端タイルからのダイアログ表示・キャンセルを確認する。利用中DBに検証列は作らない。低影響の表示削除なので構造を写すだけの新規テストは追加しない。L-048既存の列追加入口を確認、L-058不要ボタンは操作ごと除去、L-059実ブラウザーで残る入口を確認。API/DB変更なし。

独立したmain起点のPRにし、未マージの自動保存PR#5へ依存させない。ローカルWebの確認・反映では、稼働中の自動保存画面を巻き戻さず両変更を含むプレビューを作る。
