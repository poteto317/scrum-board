# 説明ブロックを好きな位置に追加する（アイテム #64）

## 背景

カード要件:

- 説明で、好きなところに入力できるようにする。
- 現状は先頭、もしくはテキストのあるところの次の行（Enter 分割）を選ばないと新しい段落を置けない。
- Notion のように好きなところにテキストなどのブロックを追加したい。

現状実装:

- `DescriptionBlocksEditor` が `description` / `solution` を `\n` 区切りの段落配列として編集する。
- 新規段落は **Enter → `splitDescriptionBlock`** のみ。ブロック間の `gap` は見た目だけでクリック挿入が無い。
- リンクはツールバー「リンク」→ 既存ダイアログで **現在フォーカス中のブロック内**に Markdown リンクを挿入（別ブロック型ではない）。
- 永続は opaque な文字列（API・上限は既存どおり Unicode コードポイント 10000。文言の「文字」も同じ意味。変更しない）。

## 決めたこと

| 事項 | 採用 |
|------|------|
| 挿入のきっかけ | **1A** ブロック間の隙間・先頭前・末尾後をクリック／タップすると挿入 UI を開く |
| 追加できるもの | **2B** Notion 風の小さなメニュー（初版: **テキスト** / **リンク**） |
| 対象画面 | **3A** 説明とソリューションの両方（同一 `DescriptionBlocksEditor`）。ソリューションは現状リンクダイアログ未配線のため、**メニュー「リンク」用に説明側と同型のダイアログ配線を本プランに含める**（別機能にしない） |
| 末尾の常設空行 | **4B** 常設しない。挿入操作のときだけ空ブロックを作る |
| データモデル | 変更なし（`\n` 区切り文字列・リンクは既存 Markdown） |
| Enter / Backspace | 現行どおり維持 |
| ツールバー「リンク」 | 現行どおり維持（選択範囲への挿入）。メニュー「リンク」は別経路（下記） |

未回答の 1・3・4 は推奨を採用。2 はユーザー指示どおり **2B**。

## 目的と受け入れ条件

1. ブロックとブロックの間（および先頭前・末尾後）をクリック／タップすると、そこにブロックを追加するためのメニューが出る。
2. メニューから **テキスト** を選ぶと、その位置に空のテキスト段落が挿入され、キャレットがその段落先頭に入る。
3. メニューから **リンク** を選ぶと、その位置に空のテキスト段落を挿入したうえで既存のリンク追加ダイアログを開き、確定するとその段落にリンク Markdown が入る（キャンセル時は空段落を残すか消すかは「リンクキャンセル」節）。
4. 説明ページとソリューションページの両方で同じ操作ができる（ソリューションでもメニュー「リンク」→ダイアログが動く。未配線のままテキストだけ、にはしない）。
5. Enter 分割・先頭 Backspace 結合・ツールバーリンク・Unicode コードポイント 10000 上限・IME composition 中の入力規則は壊さない。
6. disabled 中は隙間のクリック／タップでもメニューを出さない／挿入しない。
7. キーボード: メニューは Esc で閉じる。メニュー項目は矢印＋Enter またはクリックで選べる（最低限: フォーカス可能ボタン列）。
8. 背景の live refresh（L-775）中でも、編集中のブロック配列を poll 応答で不意に差し替えない既存ガードを維持する。
9. **末尾への常設空行は置かない**（4B）。利用者がメニューから明示挿入した空段落は現行どおりシリアライズされる。隙間を連打して空段落を複数作ることは **許可**する（常設行との混同を避けるため「連打防止」はしない）。

## 挿入 UI（詳細）

### ヒット領域

- 各ブロック間にクリック／タップ可能な「隙間」行（高さは既存 `gap` より広げて 8〜12px 相当のヒット領域）。
- 先頭ブロックの上・最終ブロックの下にも同様のヒット領域を置く。
- エディタは通常常に最低 1 つの textarea（空なら `['']`）を持つ。その上下の隙間で `i = 0` および `i = blocks.length` の挿入をカバーする。
- **タップはクリックと同じ経路**。フォーカス奪取防止は既存リンクボタンに合わせ、`mousedown`（ポインタダウン）で `preventDefault` する。タッチ専用の別 API は初版で増やさない。

### メニュー（2B）

隙間のクリック／タップで、その挿入インデックス `i`（`0..=blocks.length`）に紐づくポップオーバー／インラインメニューを開く。

| 項目 | 動作 |
|------|------|
| テキスト | `insertEmptyBlockAt(blocks, i)` が成功したら emit → 新ブロックにフォーカス。失敗（null）ならメニューを閉じ、上限エラーを既存 `lengthError` に出す |
| リンク | **先に** `insertEmptyBlockAt` を試す。null ならダイアログを開かず上限エラーのみ。成功したらそのブロック index を focused にし、選択範囲 0,0 で既存リンクダイアログを開く |

#### `insertEmptyBlockAt(blocks, i)`

- `i` は `0..=blocks.length`。範囲外は null。
- 結果は `blocks` の `i` 位置に `''` を 1 つ挿入した配列。
- シリアライズ後の Unicode コードポイント長が上限を超えるなら **null**（挿入しない）。空文字追加でも区切りの `\n` で 1 コードポイント増える点に注意。

初版のメニュー項目は上記 2 つのみ。見出し・リスト・画像などのブロック型は対象外（ストレージも拡張しない）。

### リンクキャンセル

- ダイアログをキャンセル／閉じたとき: **挿入した空段落は残す**（テキスト挿入と同じ状態）。利用者は Backspace 結合で消せる。
- ダイアログ確定失敗（上限超過など）: 既存リンク挿入の失敗挙動に従い、空段落は残す（挿入時点では既に空段落＋`\n` 分は上限内）。

### 閉じる条件

- Esc、メニュー外クリック／タップ、項目選択後、別の隙間をクリック（先を閉じて新位置で開く）。

## アプローチ比較（採用は隙間＋メニュー）

| 案 | 内容 | 採否 |
|----|------|------|
| A | 隙間クリックで即テキスト挿入 | 2B でないため不採用（メニュー無し） |
| B（採用） | 隙間クリック → テキスト／リンクメニュー | 要件 2B と Notion 感を満たす |
| C | `/` スラッシュコマンドのみ | 隙間クリック要件（1A）を満たさないため主経路にしない（将来拡張可、初版対象外） |

## 非対象（初版）

- ブロック型の永続スキーマ変更、ネスト、ドラッグ並べ替え、スラッシュコマンド、画像・見出しなどの新タイプ。
- ブロック内の余白クリックによるキャレット位置での分割（1B）。分割は従来どおり Enter。
- API / DB 変更。

## 関連知見（実装時に確認）

- **L-775**: 操作中の poll 適用で配列差し替え → 編集中は既存どおりガード。メニュー表示中（まだ dirty でなくても）も、開いた挿入 index がずれないよう poll で blocks を差し替えない／メニューを閉じる。
- **L-037 / L-040**: 遅延応答・世代。挿入後の focus と value() effect のエコー（`pendingEcho`）を壊さない。カード切替・ルート離脱ではメニューを破棄し、リンクダイアログ open 中は busy／世代で古い確定を捨てる（説明のリンク実装と同型）。
- **L-453**: 連続する状態更新で片方を巻き戻さない（挿入と linkRequest の順序）。
- **L-012**: 本機能に「確認ダイアログ後の再確認」経路は無い（N/A）。空段落挿入は通常の textChange → dirty／autosave に乗るだけ。
- **L-835**: メニューと textarea のインタラクティブ入れ子に注意（メニューは editor 外または role=menu）。
- **L-002**: 「キャンセル＝失敗＝空」を混同しない（リンクキャンセルは空段落残すと明示）。

## テスト方針

- 純関数: `insertEmptyBlockAt`（先頭・中間・末尾・上限超過で null）。
- コンポーネント: 隙間クリックでメニュー表示、テキスト選択で空ブロック＋フォーカス、リンク選択でダイアログ経路、disabled で無効、Esc で閉じる。
- 回帰: Enter split / Backspace merge / ツールバーリンク / composition / ソリューションページの `lengthErrorMessage`。
- 手動: 説明・ソリューションで間・先頭・末尾にテキスト／リンク追加、Enter 既存操作、上限付近。

## 手動チェックリスト

1. 2 段落ある説明で間の隙間をクリック → メニュー → テキスト → 空行に入力できる。
2. 末尾下の隙間からリンク → ダイアログ確定 → リンクが表示・保存される。
3. リンクダイアログをキャンセル → 空段落が残り、Backspace で前と結合できる。
4. ソリューションページでも同様。
5. Enter / ツールバーリンクが従来どおり動く。
