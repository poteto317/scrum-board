# ワンクリックでコマンドを取得する

**カード:** http://127.0.0.1:4200/cards/39  
**タイトル:** ワンクリックでコマンドを取得できるようにする

## 目的

キーボードなしの環境でも、カード詳細 URL を埋め込んだ任意のコマンド文字列をワンクリックでクリップボードへ入れる。既存の「リンクをコピー」の派生。テンプレートは DB に文字列として安全に永続化する。

## 受け入れ条件

- 利用者がコマンドテンプレート（名前＋本文）を登録・更新・削除できる
- テンプレート本文はプレースホルダ `{{url}}` を含められる。コピー時に当該カードの絶対詳細 URL（`origin + /cards/{number}`）へ置換する
- ボードの各カードと詳細画面から、登録済みテンプレートを選んでワンクリックコピーできる
- 成功・失敗が利用者に伝わる（黙って失敗しない）
- サーバーはテンプレートを実行・解釈せず、UTF-8 文字列としてのみ保存する
- バックログは対象外

## 決めたこと

| 事項 | 採用 | 理由 |
| --- | --- | --- |
| テンプレートの範囲 | グローバル一覧（カードごとではない） | カード本文の「任意登録」＋ URL の動的埋め込み |
| 保存先 | MySQL テーブル `command_templates` | ユーザー指定（DB）。端末ローカルにしない |
| プレースホルダ | リテラル `{{url}}` のみ（大文字小文字区別）。他の `{{…}}` は置換しない | 解釈を増やさない |
| 置換の場所 | **フロントのみ**（コピー直前）。API はテンプレート原文を返す | サーバーでシェル実行や eval をしない |
| 初期データ | 空。UI に追加方法の短い案内 | 推奨どおり |
| UI 配置 | ボード各カード＋詳細。リンクコピーの隣にメニュー。登録・編集は詳細側のダイアログ | 推奨どおり |
| バックログ | 対象外 | リンクコピーと同様 |
| 履歴 | テンプレート変更はカード履歴に載せない | グローバル設定でありカード変更ではない |

## セキュリティ（文字列として登録）

1. **型:** JSON の `name` / `template` は JSON 文字列のみ受理。`null`・数値・配列・オブジェクトは 400。未知フィールドは 400。
2. **正規化:** `name` は前後空白を trim。`template` は前後空白を保持し、trim しない。空の name / template は 400。LF・TAB などの制御文字は拒否する。
3. **制御文字:** `unicode.IsControl` に当たる rune（NUL・CR・LF・TAB 等）を含む値は拒否（assignee と同方針。L-083）。
4. **長さ:** `name` 1〜60 Unicode 文字、`template` 1〜2000 Unicode 文字。超えたら 400。
5. **UTF-8:** 不正 UTF-8 は 400。
6. **永続化:** プレースホルダ付きのまま TEXT 列へ **プレースホルダクエリのみ**で保存。連結 SQL 禁止。
7. **実行しない:** サーバー・クライアントともテンプレートをシェル／`eval`／`Function` に渡さない。コピーは既存 `copyText`（Clipboard API）のみ。
8. **置換:** クライアントは文字列の単純置換（`split`/`join` または一括 replace）で `{{url}}` → 絶対 URL。URL は既存 `cardDetailUrl` の結果のみ。テンプレートを HTML として挿入しない（Angular のテキストバインディング）。
9. **ログ:** エラー応答・ログにテンプレート全文を載せない（L-017）。固定の短い message。
10. **件数上限:** 全体で最大 50 件（超過は 400）。DoS・UI 肥大の抑止。ワークスペース概念は無い。

## データモデル

```sql
CREATE TABLE IF NOT EXISTS command_templates (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  name VARCHAR(60) NOT NULL,
  template VARCHAR(2000) NOT NULL,
  position INT NOT NULL DEFAULT 0,
  created_at DATETIME(6) NOT NULL DEFAULT CURRENT_TIMESTAMP(6),
  updated_at DATETIME(6) NOT NULL DEFAULT CURRENT_TIMESTAMP(6) ON UPDATE CURRENT_TIMESTAMP(6)
);
```

起動時マイグレーションでテーブルが無ければ作成（既存の `Initialize*` パターン）。

## API

| 方法 | パス | 内容 |
| --- | --- | --- |
| GET | `/api/command-templates` | `{ "templates": [ { id, name, template, position }, ... ] }`（`position` 昇順、同値は `id`） |
| POST | `/api/command-templates` | body: `{ "name", "template" }` → 201 + 作成行。`position` は末尾 |
| PATCH | `/api/command-templates/{id}` | body: `name` / `template` の少なくとも一方（部分更新）。未知フィールド・型不正は 400 |
| DELETE | `/api/command-templates/{id}` | 204。無い id は 404 |

カード JSON・ボード JSON にはテンプレートを埋め込まない（別 GET）。フロントはボード／詳細表示時に一覧を取得してキャッシュしてよい（作成・更新・削除後は再取得または局所更新）。

## UI

### コピー（ボード・詳細）

- リンクコピーボタンの近くに「コマンド」ボタン（`aria-haspopup="menu"`）。
- 押すと登録済みテンプレートのメニュー。各項目クリックで `resolveCommand(template, url)` → `copyText`。
- 0 件のときはメニューに「コマンドが未登録です。詳細画面で追加できます。」（コピー不可）。
- 成功「コマンドをコピーしました」／失敗「コマンドをコピーできませんでした」を既存のリンクコピーと同様 `aria-live`（ボードは共有 live、詳細は可視短文可）。約 2 秒で消す。コンポーネント破棄時は `clearTimeout` でタイマー解除（L-108。copy-card-link 設計と同様）。

### 管理（詳細画面のみ）

- 「コマンドを管理」でダイアログ: 一覧・追加フォーム（名前・本文）・各行の編集／削除。
- 本文のヘルプ: 「`{{url}}` はこのカードのリンクに置き換わります。」
- バリデーション失敗（400）は API の message を表示（L-057）。
- POST / PATCH / DELETE の通信失敗・5xx も成否を伝える（成功トーストまたは短い成功文＋失敗文）。黙って閉じない（L-001 / L-057）。

## フロント構成

- `command-template.ts`: 型、`resolveCommand(template, url)`（純粋）、表示用定数
- `command-templates` API メソッドを `api.ts` に追加
- コピーフィードバックはリンク用とメッセージ文言を分けてよい（共通化してもよいが必須ではない）
- ボード: メニュー UI。詳細: メニュー＋管理ダイアログ

## 非要件

- テンプレートの並び替え UI（初期は作成順の `position` 末尾付与のみ。将来拡張可）
- カードごとのテンプレート、サーバー側 URL 置換 API、Web Share、バックログボタン
- シェルの自動実行、カスタムプレースホルダの追加

## 検証方針

- Go: Normalize の境界（制御文字・長さ・型）、CRUD、件数上限、SQL インジェクションにならないこと（プレースホルダ）、マイグレーション
- フロント: `resolveCommand`（複数 `{{url}}`・未使用プレースホルダ・他の `{{x}}` 非置換）、コピー成功／失敗、メニュー 0 件、管理 CRUD のモック、ボードで遷移しないこと
- 配線（L-060）: ボード／詳細からコマンドメニューと管理ダイアログを外すと落ちるテストを置く
- ドキュメント（L-203）: README・`docs/api.md`・verification を本機能に合わせて更新する
- 手動: 実クリップボードに置換後の文字列が入ること
