## 決めたこと（推奨案を採用）

| 項目 | 決定 |
| --- | --- |
| スコープ | **MVP**: アイテム詳細の AI チャット＋設定の利用状況表示。エージェント自動操作・ボード横断チャットは対象外 |
| 置き場 | アイテム詳細内のパネル（そのアイテム文脈）。ボード横断入口は後続 |
| 能力 | title／description／comments を文脈に Q&A・要約・文案提案。**適用先は description と comments のみ**（title は文脈専用）。書き込みはチャット API の外 |
| 適用の責務 | **チャット API は本文を変更しない。** FE が確認 UI のあと既存 `PATCH /api/items/{id}`（description）／`POST /api/items/by-number/{n}/comments` だけを呼ぶ |
| パネル表示 | **セッションありかつ `canEdit` のときのみ** AI パネルを出す。閲覧のみ・未ログイン public では非表示 |
| クレジット | 既存 `ANTHROPIC_API_KEY` を使用。**アプリ側でトークン／回数を集計**して表示。Admin／Usage API 不使用は #48 で方針確定。「残クレジット」表示・上限は後続（#51/#54） |
| 利用状況の閲覧 | `GET /api/ai/usage` は **ログイン済みなら誰でも可**（ワークスペース全体の累計） |
| 設定 UI | ルート `/settings`（ヘッダー `open_settings`）。キー未設定案内＋アプリ集計 |
| 永続化 | **アイテム単位でサーバ保存**（再訪で履歴が残る） |
| プロバイダ | Claude のみ（既存 `aiformat`／SDK と同系統） |
| 同時実行 | refined と **同一セマフォを共有**（超過 429）。利用者別レート等の課金防御は後続（#58）。利用上限・残量は #51/#54 |
| 応答方式 | 初期は非ストリーム。ストリーミングは後続可 |

## 非目標（MVP ではやらない）

- ボード全体の Notion 風アシスタント、ステータス変更・起票などのツール呼び出し
- Anthropic 組織の課金残額・クレジット残高の外部 API 取得
- ストリーミング UI の必須化
- コメント欄への AI 発言の混在保存（チャットは専用ストア）
- キーの UI からの保存（キーは従来どおりサーバ環境変数）
- 利用上限（クレジット）の設定と「残量」表示（アプリ集計の累計表示までは MVP）

## 利用者体験

1. 編集可能なアイテム詳細でのみ「AI」パネルを表示する。
2. メッセージを送り、当該アイテムの文脈付きで応答を得る。履歴は同じアイテムに紐づく。
3. 応答から「説明に反映」「コメントとして追加」を選んだとき、確認のあと FE が既存 PATCH／comments API を呼ぶ。
4. `/settings` で累計リクエスト数・入出力トークン概算と、AI 未設定時の案内を見る。

## API（正本は OpenAPI）

| Method | Path | 内容 |
| --- | --- | --- |
| GET | `/api/items/by-number/{n}/ai-chat` | 履歴。セッション＋編集可。キー未設定でも可 |
| POST | `/api/items/by-number/{n}/ai-chat` | `{ "message" }`。セッション＋編集可。キー未設定は 503 |
| DELETE | `/api/items/by-number/{n}/ai-chat` | 履歴クリア。セッション＋編集可 |
| GET | `/api/ai/usage` | 集計＋ `configured`。ログイン可 |

- メッセージ長 4000、モデル文脈 20 往復、保存 200 件、hard delete CASCADE（実装プラン／コードで固定済み）。
- 失敗は上流文言をクライアントへ漏らさない。
