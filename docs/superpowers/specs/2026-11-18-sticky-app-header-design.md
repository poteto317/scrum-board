# ヘッダー固定設計（アイテム #67）

## 背景

カード要件:

- ヘッダーを固定して、画面を下にスクロールしても常に表示されるようにする。

現状: `app.html` の `.app-header`（ブランド・プロジェクト切替・Personal workspace）は通常のドキュメントフロー。ウィンドウ（document）を下へスクロールすると画面外へ消える。左サイドバーは `.app-body` 内の別要素。モーダルは `<dialog class="modal-backdrop">` を `showModal()` で開き、ブラウザの **top layer** に乗る（CSS 上は `position: fixed; z-index: 10` もあるが、前面判定は top layer が支配する）。ボード等のコマンドメニューは `position: fixed; z-index: 2〜6`。コピー成功バナーは `position: fixed; z-index: 20; top: 16px`。

## 決めたこと

| 事項 | 採用 |
|------|------|
| 固定範囲 | **上部 `.app-header` のみ**（1A）。サイドバーやボード列見出しは対象外 |
| 実装方式 | **`position: sticky; top: 0`**（2A）。`fixed`＋本文パディングは使わない |
| 見た目 | **既存の下枠線のまま**。スクロール専用の影は付けない（3A） |
| z-index | **`z-index: 5`**。ボードの fixed メニュー（最大 6）**より下**でよい（メニュー操作をヘッダーが覆わない）。モーダルは top layer のためヘッダー z-index では前面に出ない（4A） |
| コピー成功バナー | 既存どおり **ヘッダーより上**（z-index 20）。今回の変更対象外 |
| 対象画面 | シェル共通のため全ルートで同じ CSS |
| モバイル | 同じ sticky。ヘッダー高さは既存どおり 59px。`.app-body` の `min-height: calc(100vh - 67px)` は今回触らない（既存の近似） |

推奨案を採用した事項: 1A〜4A（ユーザー指示「推奨でOK」）。z-index はレビューでメニュー最大 6 との関係を明確化（ヘッダーは 5＝メニューより下）。

## 目的と受け入れ条件

1. **document（ウィンドウ）の縦スクロール**中、`.app-header` がビューポート上端に張り付き、ブランド・プロジェクト操作が使える。主な検証画面はボード（ページが縦に伸びる場合）と詳細。
2. ボードの **横スクロール**（`.board-scroll`）やバックログの **内側スクロール**（`.backlog-scroll`）だけでは、ヘッダーはもともと外にあるため「消えない」ことが普通。受け入れ 1 の主軸は document 縦スクロール。内側スクロールでヘッダーを追従させることは初版対象外。
3. サイドバーは従来どおり document スクロールで動いてよい（固定しない）。
4. モーダル（`<dialog>` top layer）表示中、ヘッダーがダイアログの前面を奪わない。
5. 既存のヘッダー操作とナビ遷移が壊れていない。
6. sticky を無効化する祖先 `overflow` を新たに足さない。

## 実装方針

- 主な変更は `frontend/src/app/app.css` の `.app-header`。
  - `position: sticky; top: 0;`
  - `z-index: 5;`
  - `background: var(--paper);` は既存のまま（本文が透けない）
- HTML / `app.ts` のロジック変更は原則不要。

## テスト方針

- ユニット（`app.spec.ts`）: **クラスに適用された computed style** で `position === 'sticky'`、`top` が `0px`、`zIndex` が `'5'`（または数値 5）を固定する。視覚的な張り付きは jsdom では検証しない。
- 既存回帰: sticky 追加後も `App` のプロジェクト切替／`ProjectSession` の busy（L-842）テストが緑のままであること。
- 手動:
  - document 縦スクロールでヘッダー残存（ボード／詳細）
  - モーダル前面（dialog top layer）
  - プロジェクト切替が使える
  - ボード列見出しは固定しない
  - ボードでコマンドメニューを開いたときヘッダーがクリックを奪わない（メニューが上）
  - バックログの内側スクロールのみでは「ヘッダー追従」は初版スコープ外（document が伸びない限りヘッダーは通常どおり見える）
