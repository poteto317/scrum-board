# プロダクトバックログの並び替えアイコン非表示（アイテム #47）

## 背景

プロダクトバックログでは行（詳細リンク以外）をドラッグ／長押しで並び替えできる。左端の `⋮⋮` ハンドルは見た目の手がかりとして冗長で、カード要件は「左側にあるアイコンは必要ない」。

## 決めたこと

| 事項 | 採用 |
|------|------|
| 見た目のハンドル | **`⋮⋮` ボタンを削除**。行の `.backlog-drag-zone` ドラッグは現状どおり（詳細リンクは除外） |
| キーボード並び替え | **維持**。順位（rank）をフォーカス可能なボタンにし、↑↓で隣へ移動。`aria-label` で「移動（ドラッグまたは上下矢印キー）」を案内 |
| フッター案内 | 「ハンドルをドラッグ…」→「**行をドラッグ、または上下キーで**優先順位を変えられます。」 |
| 範囲 | **プロダクトバックログのみ**。かんばん列／カードのハンドルは変更しない |
| フィルタ中 | 既存どおり `canReorder()` が false のときドラッグ不可・キーボード無効（`aria-disabled`）。挙動は変えない（L-460 / L-472） |

## 目的と受け入れ条件

1. バックログ行に `⋮⋮`（または同等の並び替え専用グリフ）が**表示されない**。
2. フィルタ非活性かつ 2 件以上のとき、行のドラッグゾーン（詳細リンク以外）で HTML5 DnD による並び替えができる（現状維持）。
3. 同じ条件で、順位ボタンにフォーカスして ArrowUp / ArrowDown で隣接位置へ並び替えできる。
4. **キーボード**並び替え後（成功・失敗・楽観更新時）も、移動した行の順位ボタンへフォーカスが戻る。DnD 経路は現状どおりフォーカス復帰しない。
5. フッター文言がハンドル前提ではなく、行ドラッグ＋上下キーを説明する。
6. かんばんボードのハンドル・文言は変更しない。
7. 既存の並び替え API・楽観更新・409 ロールバック・ライブリージョン告知は維持する。

## UI / DOM

- `.backlog-drag-handle` と `⋮⋮` テキストを削除する。
- `.backlog-rank` を `<button type="button">` に変更する（見た目は現行の順位数字のまま。ホバー背景は控えめに既存ハンドル相当でよい）。
  - `aria-label`: `{番号} を移動（ドラッグまたは上下矢印キー）`（現行ハンドルと同じ文言パターン）
  - `aria-hidden` は付けない（操作対象のため）
  - `aria-disabled="true"` は `!canReorder() || reordering()` のとき
  - `(keydown)` で現行 `onHandleKeydown` を呼ぶ
- グリッド列からハンドル用 `auto` を外す。モバイルの `grid-template-areas` から `handle` を外し、rank を先頭にする。
- フッター文言を上記に更新する。
- フォーカス復帰セレクタは `.backlog-drag-handle` から順位ボタン（例: `.backlog-rank` または共通クラス）へ合わせる。

## 対象外

- かんばんの列／カード DnD ハンドル
- ドラッグ開始領域の拡大・縮小の仕様変更（ゾーンは現状のまま）
- タッチ専用の長押し API の新規実装（現行ブラウザの HTML5 DnD に任せる）
- キーボード並び替えの廃止

## 知見（実装時）

- L-460 / L-472: フィルタ表示中は並び替えを無効のままにする（マスター配列と表示の乖離を避ける）。今回は UI 変更のみでロジックは触らない。
- L-775: 並び替え中のライブ再取得ガードは既存を維持。今回の差分でポーリング適用を緩めない。
- フォーカス復帰: 並び替え後に消えたハンドルへ `querySelector` しないよう、新しい操作要素のセレクタに更新する（テストも同様）。
