# コマンド1件時のワンクリックコピー設計（カード #44）

## 背景

ボード／詳細のコマンドボタンは、紐付け件数に関わらずメニューを開いてから選ぶ。件数が1のときも同じ操作が必要で冗長。カード要件を更新し、「1件なら即コピー、複数ならメニュー」とする。**登録数の上限は設けない**（既存のカードごと複数紐付け・カタログ管理は維持）。

カード説明（本番 #44）も同趣旨に更新済み。

## 決めたこと

| 事項 | 採用 |
|------|------|
| 登録数上限 | **なし**（複数紐付け可） |
| 1件のとき | コマンドボタンクリックで **メニューを出さず即コピー** |
| 0件のとき | 既存どおり空メニュー／案内文 |
| 2件以上 | 既存どおりメニューから選択してコピー |
| 対象 UI | **ボード**のコマンドアイコン、**詳細**の「コマンド」ボタン |
| 管理 UI | 変更しない（複数選択・一括適用はそのまま） |
| API / DB | 変更しない |

## 振る舞い（詳細）

### ボード

**方針:** クリック時点の user activation を活かすため、`ClipboardItem` が使える環境ではクリック中に `clipboard.write` を開始し、一覧が1件のときだけ本文 Promise を解決する。1件以外・失敗・未対応環境はメニュー経路へフォールバックする。`commandMenuLoadGeneration` ガードは維持する。

1. クリックで一覧取得を開始（既存 API）
2. **ClipboardItem 経路（優先）:** 1件ならクリップボードへ書き込み成功フィードバック、メニューは開かない。0件・複数・取得失敗ならメニュー経路へ
3. **メニュー経路:** 読み込み中表示可。成功後 0件＝空案内、2件以上＝一覧、1件（フォールバック時）＝`copyResolved` 後に閉じる。失敗時は `commandMenuError`（0件扱いしない）
4. 確定前にメニューを閉じた場合は generation ガードでコピーしない

### 詳細

1. `cardCommands.templates()` は既にロード済み（またはロード中）
2. クリック時:
   - ロード中ならメニューを開き読み込み表示（既存）
   - ロード**失敗**（`loadError`）: メニューを開きエラー表示（既存）
   - **1件:** 即コピーしメニューは閉じたまま（トグルで開かない）
   - **0件 / 2件以上:** 既存のトグル（開閉）

## 対象外

- カタログ CRUD、カードへの紐付け上限、一括適用／デフォルト
- コピー本文の組み立て（`{{url}}` / `AppOrigin`）の仕様変更
- バックログ画面

## 受け入れ条件

1. 紐付け1件のカードで、ボードのコマンドボタン1クリックでクリップボードへコピーされ、**一覧確定後にメニューが残らない**（読み込み中の一時表示は可）
2. 紐付け2件以上では従来どおりメニューから選べる
3. 紐付け0件では案内が出る。**通信失敗時は空案内ではなくエラー表示**
4. 詳細画面でも同様（1件即コピー／0・複数はメニュー／失敗はエラー）
5. 複数紐付け・管理 UI は従来どおり動く

## 知見

L-001（成否を見ない成功扱い）: コピー失敗時は既存フィードバック。一覧失敗を0件扱いにしない。generation / open カード ID ガードを維持（対象カードのずれ防止）。
