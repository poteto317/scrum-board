# サイドメニューの開閉（アイテム #78）

## 背景

カード要件:

- ChatGPT などにあるように、開閉のアイコンをサイドメニューの右上に用意して、それで開閉できるようにする。

現状:

- `aside.app-sidebar`（幅 220px）に「ボード」「バックログ」ナビとお気に入り一覧がある（#60 で新設）。
- 開閉・折りたたみは無い。狭い幅（`max-width: 680px`）でもサイドバーは常時フル幅。
- ヘッダー右端には別用途のハンバーガー（#69）があり、本機能とは独立。

## 決めたこと

| 事項 | 採用 |
|------|------|
| 閉じた見た目 | **1B** 細いアイコンレールを残す（完全非表示ではない） |
| 永続化 | **2A** `localStorage` で端末単位（サーバ prefs にはしない） |
| 閉じているときの開き方 | **3A** レール上端の同じトグルで開ける（サイドバー領域を離れない） |
| 狭い画面 | **4A** 広い画面と同じトグル。自動では閉じない |

ユーザー回答: `1B`。未回答は推奨（2A・3A・4A）。

### 検討したが採らなかった案

- **完全に畳む（1A）**: 要件回答で 1B を選択したため不採用。
- **サーバ prefs（2B）**: Basic Auth 共有ワークスペースだと他端末・他利用者のレイアウト嗜好まで共有される。UI クロムの端末好みには不向き。
- **ヘッダー左にトグル（3B）**: サイドバー外に操作が分かれ、#69 ハンバーガーとも混線しやすい。
- **狭い画面で初期閉じ（4B）／ドロワー（4C）**: 初版の範囲を広げる。必要なら後続。

## 目的と受け入れ条件

1. 展開中のサイドバー右上に開閉トグルがあり、クリックで **展開 ↔ アイコンレール** を切り替えられる。
2. レール状態では幅を細い固定幅にし、ナビはアイコンのみで「ボード」「バックログ」へ遷移できる。accessible name は各 `<a>` の **`aria-label` のみ**（「ボード」「バックログ」）。装飾アイコンは `aria-hidden="true"`。任意で同文言の `title` を付けてよい。可視テキストノードは出さない（`sr-only` も使わない）。お気に入りの見出しと一覧（空表示含む）は **`@if (!collapsed())` で DOM から外す**（`hidden` や CSS 非表示だけにしない。フォーカス可能な隠れリンクを残さない）。
3. レール状態でもトグルはサイドバー上端にあり、押すと展開に戻る（トグル自体が画面から消えて戻せなくなる状態にしない。L-475）。
4. 開閉状態は `localStorage` に保存し、同一オリジンの再読込後も復元する。読取失敗・不正値・未設定は **展開** にフォールバックし、例外でアプリを落とさない（L-044 相当の黙った誤解釈を避け、不正は展開として扱い書き戻しは任意でよいが失敗を成功扱いにしない）。
5. 保存は開閉トグル操作のたびに行う。`localStorage` 書込失敗時は画面上の開閉は反映してよいが、次回復元は保証しない（失敗を黙って「永続成功」と断定する文言は出さない）。読取・書込は専用ヘルパ経由（コンポーネントから `localStorage` 直叩きを増やさない。L-476）。
6. トグルはネイティブ `<button type="button">`。`aria-expanded` は展開時 `true`／レール時 `false`。`aria-controls` でサイドバー本体（または折りたたみ対象の内容ラッパ）を指す。`aria-label` は状態に応じて「サイドバーを閉じる」／「サイドバーを開く」。`keydown` で `Enter` または `Space` かつ `event.repeat` のときは `preventDefault` し、長押しによる連続トグルを防ぐ（L-408。単発のキー・マウス click は通す。任意で `click` の `detail > 1` も無視してよい）。
7. 狭い幅（既存 `680px`）でも同じトグルとレール挙動。ビューポート変更だけでは開閉状態を自動変更しない。
8. ログイン画面など `showChrome() === false` のときはサイドバーごと出ない（現状どおり）。`collapsed` の storage 読取は `App` の構築時／`ngOnInit` で **1 回だけ**行い、`showChrome` の真偽やその後の変化では再読取・リセットしない（ログイン往復で in-memory の開閉状態を消さない）。
9. ボード／バックログ／お気に入りの既存リンク・ルーティング・FavoritesSession の取得ロジックは変えない（表示の出し分けのみ）。
10. ユニットテストで少なくとも次を固定する: (a) トグルで `.app-sidebar` にレール用 class／属性が付く、(b) レール時にお気に入り節が出ない、(c) 不正／欠落の storage 値で展開になる、(d) トグル後に storage へ期待キーが書かれる（モック可）。

## 用語

- **展開**: 現行相当のフル幅サイドバー（ナビ文言＋お気に入り）。
- **レール**: 細いアイコン列。ナビはアイコンのみ、お気に入り非表示。
- **開閉トグル**: サイドバー上端（展開時は右寄せ）のボタン。

## UI

### レイアウト

- `.app-sidebar` に状態 class（例: `.is-collapsed`）または `data-collapsed="true"` を付ける。
- 展開幅: 現行 `220px` を維持。
- レール幅: **52px**（padding 込み。アイコンボタンが収まる固定値。CSS 変数化してよい）。
- サイドバー先頭にヘッダー行（`.sidebar-toolbar`）を置き、右端（レール時は中央寄せ可）にトグルを置く。
- トグルのアイコンは既存のインライン SVG／簡易図形でよい（外部アイコンセット新規導入はしない）。展開中は「パネルを閉じる」、レール中は「パネルを開く」が分かる図形。
- ナビのレール時アイコン: ボードは既存ボード見出しの ▥ 系、バックログは簡易リスト図形など、テキスト無しでも区別できる 2 種。展開時は従来どおり可視テキスト。レール時の accessible name は受け入れ条件 2 のとおり（`aria-label` 固定、アイコンは `aria-hidden`）。
- お気に入り節: 展開時のみ描画（`@if (!collapsed())`）。レール中にフォーカス可能な隠れリンクを残さない。

### アニメーション

- 幅の transition は任意（あってよいが必須ではない）。必須にしない場合は瞬時切替で可。
- 必須要件は状態と a11y。モーションは好みの差としてレビュー指摘にしない。

## 状態と永続化

- FE のみ。API・DB・マイグレーションは作らない。
- キー: `scrumboard:sidebar-collapsed`（既存 `scrumboard:…` 系に合わせる。文字列 `"1"` = レール、`"0"` = 展開）。
- 読取: `"1"` のみレール。それ以外（`"0"`・空・不正・例外）は展開。
- 書込: トグル後に `"1"` / `"0"`。`try/catch` で握り、失敗時も in-memory の signal は新しい状態のまま。
- 初期化: `App`（または小さな `SidebarCollapseStore` injectable）の構築時／`ngOnInit` で 1 回読取。Signal `collapsed` を単一の正本にする。`showChrome` の変化では再読取しない（受け入れ条件 8）。
- テストでは storage を差し替え可能にする（ヘルパ引数または injectable）。

## 対象外

- サーバ永続・ユーザー別 prefs
- モバイル専用ドロワー／オーバーレイ
- ビューポート連動の自動開閉
- お気に入りのレール時アイコン一覧
- キーボードショートカット（`[` 等）の新設
- ヘッダーハンバーガー（#69）への統合
- サイドバー幅のドラッグリサイズ

## 知見（実装時）

- **L-475**: トグルが常に操作可能（レールでも残す）。
- **L-044**: 不正 storage をレールと黙認しない（展開へ）。
- **L-476**: storage アクセスはヘルパ／小さな store に閉じる。
- **L-408**: トグルは単純な状態反転。開閉でフォーカス先を別ボタンへ移さない。加えて受け入れ条件 6 の Enter/Space `event.repeat` 抑止（フォーカス残留と組）。
- **L-835**: トグルをリンクの入れ子にしない。ナビは `<a>`、トグルは `<button>`。
- **L-879**: 該当するモーダル連動は無し（本機能スコープ外）。

## 実装プランの分割目安

1. storage ヘルパ＋初期状態の単体テスト
2. App シェルのトグル／レール CSS／お気に入りの出し分け＋コンポーネントテスト
3. 全体検証（`npm test` などプロジェクト手順）

## 直せない／残す制約

- Basic Auth 共有でも開閉は端末の `localStorage` 単位（タブ間は `storage` イベント同期は初版対象外）。
- レール幅 52px はアイコン可読性のための固定。ユーザー任意幅は対象外。
