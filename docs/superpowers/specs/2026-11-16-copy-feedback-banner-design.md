# コピー結果を上部中央のメッセージカードで目立たせる（アイテム #45）

## 背景

詳細画面のコピー結果は小さめの文言で目立ちにくい。ボードでは `aria-live` のみで視覚表示がない。リンク／コマンドのコピー成功・失敗を、両方の画面で同じように気づけるようにする。

カード説明: ページ上部中央にメッセージカード風。短時間で自動消去。成功は緑系、エラーは赤系背景。

## 決めたこと

| 事項 | 採用 |
|------|------|
| 置き方 | viewport 上部中央の **fixed** メッセージカード（1A） |
| 見た目 | 成功=緑系背景、失敗=赤系背景、**アイコン付き**（2B） |
| 自動消去 | **約 3 秒**（現状 2 秒より長く。3A） |
| 実装 | 既存 `LatestCopyFeedback` / `CopyFeedbackState` を拡張し、ボード・詳細で共有コンポーネント（4A） |
| 文言 | 既存 `COPY_LINK_*` / `COPY_COMMAND_*` を維持 |
| 対象操作 | リンクコピー・コマンドコピー（現状と同じ経路） |
| 対象外 | 保存状態・並べ替えエラー・他の通知の統一、バックログ専用の別 UI、グローバル toast サービス新設 |

## 目的と受け入れ条件

1. ボードでリンクまたはコマンドをコピーすると、画面上部中央にメッセージカードが出る。
2. 詳細でも同様に上部中央に出る（従来の小さめフィードバックは置き換えまたは非表示にし、二重表示しない）。
3. 成功時は緑系背景＋成功アイコン、失敗時は赤系背景＋失敗アイコン。
4. 表示後おおよそ 3 秒で自動消去する。新しいコピー結果は直前の表示を置き換える（既存の Latest 挙動）。
5. 共有バナーに `role="status"` と `aria-live="polite"` を付与する（ボードの現状は aria-live のみだったが、詳細と揃えて両方付ける）。
6. 既存のコピー成功／失敗の単体・コンポーネントテストが通る（表示場所・見た目のアサーションを更新）。

## UI

- カードは `position: fixed; top: …; left: 50%; transform: translateX(-50%); z-index` で他 UI の上。
- 内容: アイコン + テキスト。成功／失敗で CSS クラス（例: `--ok` / `--error`）を切り替え。
- 空メッセージのときは DOM を出さない（または `hidden`）。
- モバイルでも中央上部に収まる幅（`max-width` + 余白）。

## 状態モデル

- `LatestCopyFeedback` が単一の表示メッセージを持つ（現行）。
- 拡張: メッセージに加え **kind**（`success` \| `failure`）を保持する。`publish(message, kind)`。
- `CopyFeedbackState.show` / リンク・コマンドの announce 経路が kind を渡す（成功／失敗は既存の true/false から決定）。
- 消去タイマーは Latest 側に一本化（現状どおり Latest がクリアを所有）。個別 State のローカル message は UI が Latest だけ見るなら簡略化してよいが、テスト互換のため段階的に。

## コンポーネント配置

- 共有: 例 `CopyFeedbackBanner`（入力: `message` + `kind`）。ボード・詳細のテンプレート先頭付近に配置。
- ボード: 現行の sr-only `.copy-link-live` をバナーに置き換え（視覚 + aria-live）。
- 詳細: 現行 `.copy-link-feedback` をバナーに置き換え（二重表示禁止）。

## 知見（実装時）

- L-037 / L-040: 古いタイマーで新メッセージを消さない（現行 Latest の所有権を維持）。
- L-039: コピー後のフィードバックが必ず kind 付きで出ること。

## テスト

- 成功／失敗で kind クラスとアイコンが出ること（ボード・詳細）。
- 3 秒後に消えること（タイマーは vitest の `vi.useFakeTimers` / `vi.advanceTimersByTime` で検証。既存コピー系テストに合わせる）。
- 連続コピーで後勝ちになること。
